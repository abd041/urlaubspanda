 Homepage &amp; Country Landing Pages – Requirements The website itself must be entirely in German . All headings, filters, buttons, labels and customer-facing content should therefore be displayed in German. 1. Homepage Directly below the header, the first section should be: „ Beliebte Reiseziele “ The following destinations should be displayed: Österreich, Deutschland, Italien, Kroatien, Griechenland, Ägypten, Spanien, Südtirol, Städtereisen On desktop, 5 destinations should be visible in one row . The remaining destinations can be accessed via a horizontal slider/carousel. The complete destination card/image should be clickable. There should be no search box or large search section above the destinations . Mobile: 2. Homepage Filters Below the popular destinations, there should be a modern filter section. There should be no filter sidebar . Instead, all filters should be displayed as modern clickable icon buttons/chips . Since the homepage displays deals from all destinations, it should contain all available filters : Mit Flug All Inclusive Direkte Strandlage Adults Only Familienhotel Thermenurlaub Wellness Urlaub am See Urlaub am Meer In den Bergen Skiurlaub ab 85 % Weiterempfehlung Frühbucher Last Minute Each filter should have a suitable icon. Multiple filters Users must be able to select multiple filters at the same time . For example : Mit Flug + All Inclusive + Direkte Strandlage + ab 85 % Weiterempfehlung Selected filters should be visually highlighted, preferably using our blue brand color with white text/icon. There should also be a simple way to remove individual filters or reset all selected filters. 3. Filters must be reflected in the URL This is an important technical requirement. Whenever a user selects one or multiple filters, the selected filters must be reflected in the URL . For example: / angebote ?flug =1&amp;all-inclusive=1&amp;strandlage=1 This means a user should be able to copy and share the URL , and when another person opens that link, exactly the same filters should automatically be active and the corresponding deals should be displayed. The filter state should also remain correct when: refreshing the page opening the URL directly using the browser Back button using the browser Forward button The URL should therefore be the source of truth for the active filter state. Mobile: 4. Country Landing Pages Each major destination should have its own dedicated landing page. For example : Urlaub in Österreich Urlaub in Deutschland Urlaub in Italien Urlaub in Kroatien Urlaub in Griechenland Urlaub in Ägypten Urlaub in Spanien Urlaub in Südtirol The page should start with an H1 such as: „Urlaub in Österreich“ Directly underneath the heading, there should be a short introduction about the respective destination. This text should be individually editable for every country and suitable for SEO. After the introduction, display the icon-based filters , followed by the available deals. 5. Filters by Destination The landing pages should only display filters that are relevant to the respective destination.
